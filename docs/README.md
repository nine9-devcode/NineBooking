## เริ่มอ่านจากไหนดี

**เพิ่งเข้ามาในโปรเจก** → [architecture.md](./architecture.md) แล้วต่อด้วยหัวข้อ
[ส่งใบจอง](./flows.md#ส่งใบจอง-เส้นทางหลักของระบบ) ใน flows.md
เส้นทางเดียวนั้นแตะเกือบทุกชิ้นส่วนของระบบ

**จะแก้ฟีเจอร์ใดฟีเจอร์หนึ่ง** → หาหัวข้อนั้นใน [flows.md](./flows.md)
ตารางท้ายแต่ละหัวข้อบอกไฟล์ที่ต้องเปิดครบแล้ว

**จะเพิ่ม endpoint ใหม่** → ดูหัวข้อ "สองด่านตรวจสิทธิ์" ใน architecture.md
แล้วลอกโครงจาก route ที่ใกล้เคียงใน [api-reference.md](./api-reference.md)

**จะเล่าโปรเจกให้คนอื่นฟัง** → [interview-notes.md](./interview-notes.md)
